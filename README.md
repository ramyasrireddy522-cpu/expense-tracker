# 💰 Expense Tracker

A simple command-line expense tracker application to manage and analyze your daily expenses.

## Features
- ✅ Add new expenses
- ✅ View all expenses
- ✅ Filter expenses by category
- ✅ Calculate total spending
- ✅ Delete expenses
- ✅ Data persists in JSON file

## Installation

1. Clone the repository
```bash
git clone https://github.com/YOUR-USERNAME/expense-tracker.git
cd expense-tracker
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

## Usage

Run the application:
```bash
python main.py
```

### Menu Options
1. **Add Expense** - Enter amount, description, and category
2. **View All Expenses** - Display all recorded expenses
3. **View by Category** - Filter expenses by category
4. **View Statistics** - See total spending
5. **Delete Expense** - Remove an expense
6. **Exit** - Close the application

## Tech Stack
- Python 3.7+
- JSON (for data storage)
